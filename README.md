# 하이미디어 AI 개발자 과정

제공된 상세페이지·가로 배너·세로 배너 HTML을 바탕으로 만든 10개 화면의 가로 슬라이드 웹페이지입니다. 원본의 Pretendard 글꼴, 남색·민트 색상, 문구와 현장 면접 사진 6장을 반영했습니다.

- 휴대폰: 좌우로 스와이프
- 데스크톱: 마우스 드래그, 이전/다음 버튼, 방향키, 목차 또는 페이지 점 선택
- 긴 화면: 해당 슬라이드 안에서 세로 스크롤
- 상담 버튼: 과정·기간·국비 지원·캠퍼스·취업 지원 안내 창

`index.html`과 `assets/`를 같은 위치에 두면 별도 빌드 없이 사용할 수 있습니다. 상담 안내 창은 개인정보를 수집하거나 실제 상담을 접수하지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다.
