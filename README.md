# 하이미디어 AI 개발자 · FDE 엔지니어 과정

제공된 홍보 HTML을 바탕으로 만든 두 과정의 가로 슬라이드 웹사이트입니다. 상단 과정 선택 메뉴에서 서로 이동할 수 있습니다.

- `index.html`: AI 개발자 과정 10개 화면. 남색·민트 색상과 현장 면접 사진 6장.
- `fde.html`: FDE 엔지니어 양성과정 13개 화면. 정규 960시간과 심화 349시간의 커리큘럼, 프로젝트·멘토링, 모집 안내·FAQ와 원본 현장 사진 13장.

하이미디어 로고는 두 과정의 상단에 공통으로 표시됩니다. 글꼴과 색상, 본문은 각 원본 HTML의 구성을 따릅니다.

- 휴대폰: 좌우로 스와이프
- 데스크톱: 마우스 드래그, 이전/다음 버튼, 방향키, 목차 또는 페이지 점 선택. FDE는 상단 선택 상자로 원하는 구간에 바로 이동할 수 있습니다.
- 긴 화면: 해당 슬라이드 안에서 세로 스크롤
- 상담: AI 과정은 정보 안내 창, FDE는 모집 안내·FAQ와 원본에 제공된 전화번호 연결.

`index.html`, `fde.html`과 `assets/`를 같은 위치에 두면 별도 빌드 없이 사용할 수 있습니다. 웹사이트는 개인정보를 수집하거나 실제 상담을 접수하지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다.
