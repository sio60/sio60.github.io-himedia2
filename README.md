# 하이미디어 AI 개발자 · FDE · AI 네이티브 과정

제공된 홍보 HTML을 바탕으로 만든 세 과정의 가로 슬라이드 웹사이트입니다. 상단 과정 선택 메뉴에서 서로 이동할 수 있습니다.

- `index.html`: AI 개발자 과정 10개 화면. 남색·민트 색상과 현장 면접 사진 6장.
- `fde.html`: FDE 엔지니어 양성과정 13개 화면. 정규 960시간과 심화 349시간의 커리큘럼, 프로젝트·멘토링, 모집 안내·FAQ와 원본 현장 사진 13장.
- `ai-native.html`: AI 네이티브 엔지니어링 부트캠프 13개 화면. 하이미디어 6개월 + 2개월 통합 과정으로, 제공된 원본의 커리큘럼 210개 항목과 프로젝트·발표회 사진을 유지합니다. PDF 다운로드 및 홈페이지 상담폼에 연결합니다.

하이미디어 로고는 세 과정의 상단에 공통으로 표시됩니다. AI 네이티브 과정은 남색·민트 디자인으로 구성하고 LG 및 별도 심화과정 브랜딩을 사용하지 않습니다.

- 휴대폰: 좌우로 스와이프
- 데스크톱: 마우스 드래그, 이전/다음 버튼, 방향키, 목차 또는 페이지 점 선택. FDE는 상단 선택 상자로 원하는 구간에 바로 이동할 수 있습니다.
- 긴 화면: 해당 슬라이드 안에서 세로 스크롤
- 상담: AI 과정은 정보 안내 창, FDE는 모집 안내·FAQ와 원본에 제공된 전화번호 연결.

`index.html`, `fde.html`, `ai-native.html`과 `assets/`를 같은 위치에 두면 별도 빌드 없이 사용할 수 있습니다. 사이트 자체는 개인정보를 수집하지 않으며 AI 네이티브 상담은 하이미디어 홈페이지 상담폼으로 이동합니다. PDF 안내서는 `assets/ai-native-course-guide.pdf`입니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시합니다.
